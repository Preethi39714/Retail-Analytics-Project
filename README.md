# Retail Sales & Customer Insights Dashboard

## Project Overview
This project is a Data Analytics and Power BI dashboard project developed using Python, Pandas, Matplotlib, and Power BI.

The project analyzes retail sales data to identify:
- Sales performance
- Profit analysis
- Regional sales trends
- Category-wise sales distribution
- Customer insights
- Business KPIs

## Technologies Used
- Python
- Pandas
- Matplotlib
- Power BI
- Excel

## Features
- Sales KPI Analysis
- Profit KPI Analysis
- Regional Sales Dashboard
- Category-wise Sales Visualization
- Automated Excel Reporting
- Data Visualization Charts

## Project Files
- `retail_analytics.py` → Python analysis code
- `retail_data.csv` → Dataset
- `sales_report.xlsx` → Generated report
- `Retail_Analytics_Dashboard.pbix` → Power BI dashboard
- `charts/` → Visualization charts

## Dashboard Insights
- Identified top-performing regions
- Analyzed category sales distribution
- Generated sales and profit KPIs
- Visualized business trends using Power BI
